# وَرَقَة — تطبيق متابعة الحفظ

تطبيق Android عربي يعمل دون اتصال لمتابعة حفظ القرآن والمراجعة لدى معلّم الحلقة.

## الميزات
- خطة مولّدة من سورة الناس إلى سورة فصلت، مع مقدار وجه أو نصف وجه أو ربع وجه تمهيدي.
- دوام الأحد إلى الأربعاء، وإجازة ليوم واحد أو لفترة.
- تسجيل حفظ، لم يحفظ، غائب، أو سبب آخر. خيار «لم يحفظ» يؤجل المقطع ويزحزح ما بعده إلى أيام الدوام التالية.
- المراجعة الصغرى تلقائية من حفظ اليوم الدراسي السابق.
- مراجعة كبرى اختيارية: صفحتان يوميًا تبدأ من صفحة 604 نزولًا إلى صفحة 477.
- إحصاءات لكل طالب وسجل الأيام، مع تصدير واستعادة نسخة احتياطية محلية.

## ملاحظة تقسيم الخطة
الأسطر وحدود الآيات داخل الصفحة تقديرية ومتوازنة على عدد صفحات السورة وعدد آياتها؛ راجع مواضع الآيات على مصحف المدينة قبل اعتمادها نهائيًا. إدخال هذه النسخة لا يتطلب اتصالًا أو حسابًا، وتبقى البيانات على الجهاز.

## بناء APK
من GitHub Actions شغّل **Build Android APK**، ثم نزّل artifact باسم `waraqah-debug-apk`. ويمكن البناء محليًا بعد تثبيت Android SDK وGradle 8.9 عبر:

```sh
gradle assembleDebug
```
